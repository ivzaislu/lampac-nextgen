# TranslationSub

Модуль подписок на озвучки сериалов для **Lampa**. Позволяет подписаться на выбранную озвучку и получать уведомления о новых сериях, а проверка доступности выполняется на стороне Lampac через выбранные Online-балансеры.

Плагин Lampa подключается автоматически при включённом модуле — отдельно добавлять JS-ссылку не требуется.

## Возможности

- Подписка на озвучки сериалов прямо из карточки Lampa.
- Проверка новых серий по выбранным балансерам Lampac.
- Умное расписание через TMDB: модуль учитывает даты выхода серий и не опрашивает балансеры без необходимости.
- Отслеживание нового сезона (`auto`, `notify`, `off`).
- Учёт просмотренных серий через Lampac **TimeCode** и профили Lampa.
- Realtime-обновление интерфейса через NWS при изменении состояния подписок и прогресса.
- Хранение настроек, подписок и проекции прогресса в SQLite.

> Подписки предназначены для сериалов. Фильмы не добавляются в TranslationSub.

## Настройки в Lampa

В разделе **TranslationSub** доступны:

- интервал проверки новых серий;
- включение/отключение умного расписания TMDB;
- период обновления данных TMDB;
- период проверки завершённых сериалов;
- режим отслеживания новых сезонов;
- выбор балансеров, используемых для проверки озвучек.

Также доступна ручная команда **«Проверить новые серии»**.

## Конфигурация Lampac

Модуль включён по умолчанию в [`manifest.json`](manifest.json). Серверные параметры задаются секцией `TranslationSub` в `init.conf`:

```json
"TranslationSub": {
  "enable": true,
  "check_interval_minutes": 15,
  "tmdb_apihost": "https://api.themoviedb.org/3"
}
```

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `enable` | Включить модуль | `true` |
| `check_interval_minutes` | Частота фонового прохода планировщика | `15` минут |
| `tmdb_apihost` | API host TMDB | `https://api.themoviedb.org/3` |
| `tmdb_apikey` | API key TMDB | используется значение из `ModuleConf.cs` |

`check_interval_minutes` задаёт частоту работы фонового планировщика Lampac. Пользовательский интервал проверки подписок настраивается отдельно в Lampa.

## Хранение данных

Состояние модуля хранится в одном файле:

```text
database/translationsub.db
```

В базе находятся пользовательские настройки, подписки и профильный прогресс TranslationSub. Просмотренные серии синхронизируются из штатного Lampac TimeCode.

## Зависимости

- настроенные Online-балансеры Lampac для проверки доступных серий;
- TMDB для умного расписания;
- Lampac TimeCode для учёта просмотренных серий;
- NWS используется для realtime-обновлений интерфейса.
