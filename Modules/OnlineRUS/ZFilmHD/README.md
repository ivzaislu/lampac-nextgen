# ZFilmHD (experimental)

Metadata-only prototype, disabled in both the manifest and configuration. No Online button or playback route. Native C#; no browser or new dependencies.

The supplied network capture established a serial catalogue with voice indices, seasons and episode numbers. The observed film contract and playback authorization are not established. Do not infer a movie contract from the serial sample. No captured media URLs, cookies, account data or signed parameters are stored.

The self-check uses synthetic metadata. The separate direct observation only requests public catalogue metadata, without proxies, media requests or session replay.
