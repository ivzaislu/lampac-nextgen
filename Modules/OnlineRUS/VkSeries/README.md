# VkSeries

Онлайн-источник **VK Сериалы** на базе API **`https://api.vkvideo.ru`**. Модуль использует механику авторизации и потоков из **VkMovie**, но строит выдачу как сезоны и эпизоды.

## Интерфейс

**`IModuleLoaded`**, **`IModuleOnline`**.

## Условие (`Invoke`)

Источник добавляется только для сериалов:

- **`args.serial > 0`**.

Для фильмов и неопределённого типа возвращается **`null`**.

## Глобальный поиск

**`CoreInit.conf.online.with_search.Add("vkseries")`**.

## Поиск и структура

1. **`catalog.getVideoSearchWeb2`** ищет сериал по названию/оригинальному названию и читает **`response.albums`**.
2. Альбом трактуется как плейлист сериала или релиза, а не обязательно как отдельный сезон.
3. Несколько наиболее релевантных альбомов проверяются через **`video.getFromAlbum`** с fallback на **`video.get`**; выбирается плейлист, в котором реально распознаются сезоны и эпизоды.
4. Сезоны строятся из названий/описаний видео внутри выбранного плейлиста.
5. При открытии сезона используется тот же **`owner_id + album_id`**, а серии фильтруются по распознанному номеру сезона.
6. Потоки и субтитры берутся из **`files`** и **`subtitles`**. MP4 используется в приоритете, HLS — как fallback.

Поддерживаются формы **`S01E04`**, **`S01.E04`**, **`S01-E04`**, **`1x04`**, **`1 сезон 4 серия`**, **`Сезон 1. Серия 4`**, а для season-specific альбомов также **`4 серия`** / **`серия №4`**.

## Конфигурация

Секция в `init.conf`: **`VkSeries`** (`OnlinesSettings`).

По умолчанию: **`displayindex = 569`**, **`streamproxy = true`**, **`headers`** с **`origin`/`referer`** на **`vkvideo.ru`**.

## Подпись качества

**`OnlineApiQuality`**: для **`e.balanser == "vkseries"`** → **` ~ 2160p`**.

## HTTP

| Маршрут | Назначение |
|---------|------------|
| **`lite/vkseries`** | Поиск плейлиста, сезонов и выдача эпизодов. |
