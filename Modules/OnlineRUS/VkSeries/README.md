# VkSeries

Онлайн-источник **VK Сериалы** на базе API **`https://api.vkvideo.ru`**.

## Логика

Текущая реализация намеренно упрощена: источник не смешивает обычный поиск, showcase и VK-плейлисты.

1. Сезоны ищутся через **`catalog.getVideoSearchWeb2`** по локализованному названию.
2. Загружается только первая выдача и максимум одна дополнительная страница **`catalog.getSection`**.
3. Если локализованное название не дало ни одной валидной серии, выполняется один fallback по **`original_title`**.
4. Сезон и серия извлекаются **только из `video.title`**. Description не используется для определения S/E.
5. При открытии сезона выполняется отдельный запрос вида **`<title> N сезон`**; original title используется только как fallback.
6. Ролики фильтруются по названию сериала, явному season/episode, году (если он указан в title), шуму и наличию playable stream.
7. Сборники **`все серии`**, диапазоны **`1-7 серия`** и многочасовые ролики не считаются отдельными эпизодами.
8. Для одного сезона выбирается **один `owner_id`** с максимальным количеством уникальных серий. Источники разных владельцев больше не смешиваются в одну сезонную выдачу.
9. Внутри выбранного owner дубль серии выбирается по релевантности названия, затем по качеству, длительности и просмотрам.

Основной поисковый API — **`v=5.289`**. Если Web2 не вернул видео, выполняется fallback того же запроса на **`v=5.264`**.

## Поддерживаемые названия

- **`S01E04`**
- **`S01.E04`**
- **`S01-E04`**
- **`1x04`**
- **`1 сезон 4 серия`**
- **`Сезон 1. Серия 4`**

## Конфигурация

Секция в `init.conf`: **`VkSeries`** (`OnlinesSettings`).

По умолчанию: **`displayindex = 569`**, **`streamproxy = true`**, headers с origin/referer на **`vkvideo.ru`**.

## HTTP

| Маршрут | Назначение |
|---------|------------|
| **`lite/vkseries`** | Поиск сезонов и серий. |
