# VkSeries

Онлайн-источник **VK Сериалы** на базе API **`https://api.vkvideo.ru`**. Модуль использует анонимный VK Video token, глобальный поиск VK Video и выдаёт сезоны/эпизоды без привязки к фиксированному списку аккаунтов.

## Интерфейс

**`IModuleLoaded`**, **`IModuleOnline`**.

## Условие (`Invoke`)

Источник добавляется только для сериалов:

- **`args.serial > 0`**.

Для фильмов и неопределённого типа возвращается **`null`**.

## Discovery

Основной путь:

1. **`catalog.getVideoSearchWeb2`** ищет сериал глобально по VK Video.
2. Из **`response.albums`** собираются playlist-кандидаты с разных owner. Whitelist аккаунтов не используется.
3. Кандидаты ранжируются по совпадению названия и года. Слабое совпадение только по вхождению текста получает низкий вес, чтобы одноимённый контент не вытеснял сериал.
4. **`video.getAlbumById`** проверяет нативный **`series_object.seasons`** для любого owner, а не для одного специального аккаунта.
5. Обычный playlist читается в первую очередь через **`video.getFromAlbum`**. Метод протестирован на плейлистах разных owner и возвращает **`playlist_position`**.
6. Если **`video.getFromAlbum`** недоступен, остаётся fallback на **`video.get(owner_id, album_id)`**.
7. Так как глобальная выдача albums ограничена, модуль дополнительно проверяет запросы для пропущенных ближайших сезонов.
8. Второй канал discovery — глобальные video-результаты из того же **`catalog.getVideoSearchWeb2`**. Они используются как fallback, если playlist не дал полноценные серии или не попал в album-выдачу.

## Эпизоды

Определение эпизода использует:

- **`S01E04`**, **`S01.E04`**, **`S01-E04`**;
- **`1x04`**;
- **`1 сезон 4 серия`**, **`Сезон 1. Серия 4`**;
- для season-specific playlist: **`4 серия`**, **`серия №4`**;
- как последний fallback — **`playlist_position`** от **`video.getFromAlbum`**.

Порядок разбора номера сезона учитывает форму вроде **«1 сезон 12 серий»**: первым берётся число перед словом «сезон», поэтому количество серий не принимается за номер сезона.

Трейлеры, тизеры, короткие моменты/фрагменты и сборники «все серии / полный сезон» отбрасываются. При нескольких вариантах одной серии выбирается более релевантное совпадение сериала, затем лучшее доступное качество.

## Потоки

Потоки и субтитры берутся из **`files`** и **`subtitles`**.

Приоритет:

**2160p → 1440p → 1080p → 720p → 480p → 360p → 240p → 144p → HLS**.

Тестовые Range-запросы к URL, полученным из глобального VK Video search, вернули **HTTP 206**, поэтому этот путь пригоден и как прямой fallback источника серий.

## Конфигурация

Секция в `init.conf`: **`VkSeries`** (`OnlinesSettings`).

По умолчанию:

- **`displayindex = 569`**;
- **`streamproxy = true`**;
- заголовки **origin/referer** на **`vkvideo.ru`**.

## HTTP

| Маршрут | Назначение |
|---|---|
| **`lite/vkseries`** | Поиск сезонов и выдача эпизодов |
| **`lite/vkseries?...&direct=true`** | Прямой global-video fallback для сезона |
