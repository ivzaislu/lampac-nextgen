# VkSeries

Онлайн-источник **VK Сериалы** на базе API **`https://api.vkvideo.ru`**. Модуль получает анонимный token через нативный **`auth.getAnonymToken`** и использует глобальный поиск VK Video, без `client_secret`, `login.vk.com` и без привязки discovery к фиксированному списку аккаунтов.

## Интерфейс

**`IModuleLoaded`**, **`IModuleOnline`**.

## Условие (`Invoke`)

Источник добавляется только для сериалов:

- **`args.serial > 0`**.

Для фильмов и неопределённого типа возвращается **`null`**.

## Discovery

Основной путь:

1. **`catalog.getVideoSearchWeb2`** ищет сериал глобально по VK Video.
2. Из **`response.albums`** собираются playlist-кандидаты с любых owner.
3. Кандидаты проверяются по identity сериала и году. Для поздних сезонов год в названии playlist считается годом конкретного сезона и не сравнивается жёстко с годом премьеры сериала.
4. Owner берётся только из уже подтверждённого глобального совпадения. Затем **`video.getAlbums`** динамически и с пагинацией перечисляет его playlist, которые снова проходят identity-фильтр. Это позволяет одной находкой раскрыть много сезонов без whitelist.
5. **`video.getAlbumById`** проверяет нативный **`series_object.seasons`** для любого найденного owner.
6. Playlist читается через **`video.getFromAlbum`**; если метод недоступен, остаётся fallback на **`video.get(owner_id, album_id)`**.
7. Оставшиеся дырки сезонов добираются ограниченным числом targeted-search; каждый новый owner снова расширяется через **`video.getAlbums`**.
8. Второй канал — отдельный **video-only search**: `catalog.getVideoSearchWeb2` на API **5.282** с `content_type=video`. Для него читаются до четырёх страниц через **`catalog.getSection(section_id, start_from)`**. Этот канал используется только как строгий fallback для сезонов/эпизодов, которые не удалось получить из playlist.

Whitelist/fixed owner для discovery не используется. Если VK возвращает album с общим названием вроде **`9 Сезон`**, он принимается только после content-проверки: видео внутри должны подтверждать нужный сериал и сезон. Для массового раскрытия таких безымянных sibling-album дополнительно требуется подтверждение минимум двух разных сезонов одного owner. В live-проверке для `Южного парка` динамически найденный owner раскрыл отдельные playlist сезонов 1–20.

## Эпизоды

Поддерживаются:

- **`S01E04`**, **`S01.E04`**, **`S01-E04`**;
- **`1x04`**;
- **`1 сезон 4 серия`**, **`Сезон 1. Серия 4`**;
- для season-specific playlist: **`4 серия`**, **`серия №4`**;
- резервно — **`playlist_position`** из **`video.getFromAlbum`**, но только для реально многовидео season-playlist;
- имена файлов вида **`07 Pinkeye.mkv`** разбираются как явный номер серии и имеют приоритет над `playlist_position`.

Для названий вида **«1 сезон 12 серий»** сначала разбирается число перед словом «сезон», поэтому количество серий не принимается за номер сезона.

Трейлеры, тизеры, **анонсы**, `promo`/`preview`, короткие моменты/фрагменты и сборники «все серии / полный сезон» отбрасываются. Direct-search заметно строже playlist-пути: он должен подтвердить плотный набор минимум из трёх полноразмерных эпизодов сезона и не может самостоятельно создать сезон из случайного хвоста вроде E8/E10/E12.

## Защита от склеек сезона

VK Video часто отдаёт весь сезон или несколько сезонов одним длинным видео. Такие файлы не считаются эпизодами.

Фильтр общий для всех сериалов и отбрасывает:

- явные маркеры **«все серии»**, **«полный сезон»**, **«целиком»**, **«подряд»**, **«нон-стоп»**, **all episodes / full season / complete season**;
- диапазоны серий и сезонов: **`1-13 серия`**, **`1-3 сезоны`**, **`сезон 1-4`**;
- конструкции количества серий вроде **`1 сезон 8 серий`** — число `8` не принимается за E08;
- видео без явного номера серии длительностью от **150 минут**, если в названии/описании указан сезон;
- видео без явного номера серии длительностью от **6 часов**, даже если uploader не указал сезон;
- **одиночный файл в season-playlist без явного номера серии** — независимо от длительности;
- parent-album, где отдельные файлы являются целыми сезонами (`1 сезон`, `2 сезон`, …), не превращается через `playlist_position` в фиктивные эпизоды.

На live-данных это отделяет многчасовые склейки `Симпсонов` и `Южного парка` от нормальных episode-playlist. Для найденных playlist `video.getFromAlbum` возвращает отдельные playable-серии; например, у `Симпсонов` 1 сезона найден playlist из 13 отдельных файлов.

## Проверенные edge-cases

Автоматический parser-test запускается против реальной сборки `VkSeries` и проверяет, среди прочего:

- одиночный whole-season файл → отклоняется;
- длинный whole-season файл → отклоняется;
- **`Серии 1–20`** и multi-season ranges → отклоняются;
- обычная и короткая явная серия → сохраняются;
- filename вида **`07 Pinkeye.mkv`** → серия 7, даже если `playlist_position` другой;
- multi-item generic playlist может использовать `playlist_position`;
- single-item generic playlist не превращается в fake episode 1;
- parent playlist из файлов «1 сезон», «2 сезон» не превращается в серии.

## Потоки

Потоки и субтитры берутся из **`files`** и **`subtitles`**.

Приоритет:

**2160p → 1440p → 1080p → 720p → 480p → 360p → 240p → 144p → HLS / HLS fMP4 / HLS on-demand**.

Прямые stream URL из VK Video проверены Range-запросами с **HTTP 206**. Если VK возвращает только `files.external` без MP4/HLS, такой ролик не считается playable: на примерах `Ворониных`, `Молодёжки` и `Папиных дочек` полноценные серии в выдаче CTC оказались external-only даже после нескольких страниц поиска. Модуль сознательно не подменяет их короткими промо/трейлерами и пока не использует внешний CTC-player как stream resolver.

## Конфигурация

Секция в `init.conf`: **`VkSeries`** (`OnlinesSettings`).

По умолчанию:

- **`displayindex = 569`**;
- **`streamproxy = true`**;
- заголовки **origin/referer** на **`vkvideo.ru`**.

## HTTP

| Маршрут | Назначение |
|---|---|
| **`lite/vkseries`** | Глобальный поиск сезонов и выдача эпизодов |
| **`lite/vkseries?...&direct=true`** | Прямой global-video fallback для сезона |
