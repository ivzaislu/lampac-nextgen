# VkSeries

Онлайн-источник **VK Сериалы** на базе API **`https://api.vkvideo.ru`**. Модуль использует анонимный VK Video token и глобальный поиск VK Video, без привязки discovery к фиксированному списку аккаунтов.

## Интерфейс

**`IModuleLoaded`**, **`IModuleOnline`**.

## Условие (`Invoke`)

Источник добавляется только для сериалов:

- **`args.serial > 0`**.

Для фильмов и неопределённого типа возвращается **`null`**.

## Discovery

Основной путь:

1. **`catalog.getVideoSearchWeb2`** ищет сериал глобально по VK Video.
2. Из **`response.albums`** собираются playlist-кандидаты с любых owner.
3. Кандидаты проверяются по identity сериала и году. Для поздних сезонов год в названии playlist считается годом конкретного сезона и не сравнивается жёстко с годом премьеры сериала.
4. Owner берётся только из уже подтверждённого глобального совпадения. Затем **`video.getAlbums`** динамически перечисляет его playlist, которые снова проходят identity-фильтр. Это позволяет одной находкой раскрыть много сезонов без whitelist.
5. **`video.getAlbumById`** проверяет нативный **`series_object.seasons`** для любого найденного owner.
6. Playlist читается через **`video.getFromAlbum`**; если метод недоступен, остаётся fallback на **`video.get(owner_id, album_id)`**.
7. Оставшиеся дырки сезонов добираются ограниченным числом targeted-search; каждый новый owner снова расширяется через **`video.getAlbums`**.
8. Второй канал — глобальные **video**-результаты того же **`catalog.getVideoSearchWeb2`**. Они используются как строгий identity-проверенный fallback для сезонов/эпизодов, которые не удалось получить из playlist.

Whitelist/fixed owner для discovery не используется. В live-проверке для `Южного парка` динамически найденный owner раскрыл отдельные playlist сезонов 1–20.

## Эпизоды

Поддерживаются:

- **`S01E04`**, **`S01.E04`**, **`S01-E04`**;
- **`1x04`**;
- **`1 сезон 4 серия`**, **`Сезон 1. Серия 4`**;
- для season-specific playlist: **`4 серия`**, **`серия №4`**;
- резервно — **`playlist_position`** из **`video.getFromAlbum`**.

Для названий вида **«1 сезон 12 серий»** сначала разбирается число перед словом «сезон», поэтому количество серий не принимается за номер сезона.

Трейлеры, тизеры, короткие моменты/фрагменты и сборники «все серии / полный сезон» отбрасываются. При нескольких источниках одной серии учитываются совпадение сериала, качество, длительность и просмотры.

## Защита от склеек сезона

VK Video часто отдаёт весь сезон или несколько сезонов одним длинным видео. Такие файлы не считаются эпизодами.

Фильтр общий для всех сериалов и отбрасывает:

- явные маркеры **«все серии»**, **«полный сезон»**, **«целиком»**, **«подряд»**, **«нон-стоп»**, **all episodes / full season / complete season**;
- диапазоны серий и сезонов: **`1-13 серия`**, **`1-3 сезоны`**, **`сезон 1-4`**;
- видео без явного номера серии длительностью от **150 минут**, если в названии/описании указан сезон;
- видео без явного номера серии длительностью от **6 часов**, даже если uploader не указал сезон.

На live-данных это отделяет многчасовые склейки `Симпсонов` и `Южного парка` от нормальных episode-playlist. Для найденных playlist `video.getFromAlbum` возвращает отдельные playable-серии; например, у `Симпсонов` 1 сезона найден playlist из 13 отдельных файлов.

## Потоки

Потоки и субтитры берутся из **`files`** и **`subtitles`**.

Приоритет:

**2160p → 1440p → 1080p → 720p → 480p → 360p → 240p → 144p → HLS**.

В диагностических тестах stream URL, полученные из глобального VK Video search, успешно отвечали на Range-запросы с **HTTP 206**.

## Конфигурация

Секция в `init.conf`: **`VkSeries`** (`OnlinesSettings`).

По умолчанию:

- **`displayindex = 569`**;
- **`streamproxy = true`**;
- заголовки **origin/referer** на **`vkvideo.ru`**.

## HTTP

| Маршрут | Назначение |
|---|---|
| **`lite/vkseries`** | Глобальный поиск сезонов и выдача эпизодов |
| **`lite/vkseries?...&direct=true`** | Прямой global-video fallback для сезона |
