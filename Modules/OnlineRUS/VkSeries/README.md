# VkSeries

Онлайн-источник **VK Сериалы** на базе API **`https://api.vkvideo.ru`**. Модуль использует механику авторизации и потоков из **VkMovie**, но строит выдачу как сезоны и эпизоды.

## Интерфейс

**`IModuleLoaded`**, **`IModuleOnline`**.

## Условие (`Invoke`)

Источник добавляется только для сериалов:

- **`args.serial > 0`**.

Для фильмов и неопределённого типа возвращается **`null`**.

## Глобальный поиск

**`CoreInit.conf.online.with_search.Add("vkseries")`**.

## Поиск и структура

VkSeries больше не использует глобальный поиск плейлистов по всему VK Video.

1. Используется whitelist проверенных каналов. Сейчас подключён **`@mirserialov`** (`https://vkvideo.ru/@mirserialov/playlists`).
2. Имя канала разрешается через **`utils.resolveScreenName`** в VK `owner_id`.
3. Плейлисты канала загружаются напрямую через **`video.getAlbums`** с пагинацией.
4. Нужный сериал ищется только среди названий плейлистов доверенного канала по `title`, `original_title` и году.
5. Каждый playlist с номером сезона становится отдельным **`SeasonTpl`**. Поэтому разные сезоны могут иметь разные `album_id`.
6. При открытии сезона вызывается **`video.get(owner_id, album_id)`**, а серии строятся только из видео этого плейлиста.
7. VK-моменты/short-video, короткие фрагменты и ролики-сборники вида «Все серии» / «Полный сезон» не попадают в `EpisodeTpl`.
8. Потоки и субтитры берутся из **`files`** и **`subtitles`**. MP4 используется в приоритете, HLS — как fallback.

Прокси работает как раньше через стандартный `useproxy`/ `HttpHydra` путь Lampac и применяется ко всем VK API-запросам этого модуля.

Поддерживаются формы **`S01E04`**, **`S01.E04`**, **`S01-E04`**, **`1x04`**, **`1 сезон 4 серия`**, **`Сезон 1. Серия 4`**, а для season-specific плейлистов также **`4 серия`** / **`серия №4`**.

## Конфигурация

Секция в `init.conf`: **`VkSeries`** (`OnlinesSettings`).

По умолчанию: **`displayindex = 569`**, **`streamproxy = true`**, **`headers`** с **`origin`/`referer`** на **`vkvideo.ru`**.

## Подпись качества

**`OnlineApiQuality`**: для **`e.balanser == "vkseries"`** → **` ~ 2160p`**.

## HTTP

| Маршрут | Назначение |
|---------|------------|
| **`lite/vkseries`** | Поиск плейлиста, сезонов и выдача эпизодов. |
