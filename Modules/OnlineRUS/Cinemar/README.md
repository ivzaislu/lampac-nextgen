# Cinemar

Экспериментальный онлайн-модуль на основе Kinogo с нативным C# декодированием плейлиста.

- Исходный домен: `https://kinogo.luxury`.
- Поиск, получение страницы и плейлиста: RCH, PlaywrightHttp или нативный HTTP (`Http.BaseGet`).
- Декодирование: `PlayerFileDecoder.cs`, без отдельной страницы Playwright и без `playerjs.js`.
- Логика фильмов, сериалов, озвучек, субтитров и видео сохранена из Kinogo.
- Отдельные настройки `Cinemar`, маршруты `lite/cinemar`, `lite/cinemar/video` и `lite/cinemar/video.m3u8`, отдельные ключи кеша.

По умолчанию сохранён контрольный транспорт Playwright. Для экспериментального режима HTTP без Chromium:

```json
{
  "Cinemar": { "useplaywright": false }
}
```

RCH сохраняет приоритет при включении. Автоматического отката HTTP на Playwright нет. Кеш HTML-этапов разделён по режимам. CI запускает оба режима независимо с RCH, отключённым в обоих случаях. Успешная сборка не означает успешный доступ к провайдеру; HTTP 403/Cloudflare Challenge остаётся ошибкой интеграционного теста.
