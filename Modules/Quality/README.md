# Quality

Модуль **Quality** для Lampac NextGen: показывает лучшее найденное качество видео на постерах и в полных карточках Lampa, добавляет выбор источника в фильтр Онлайн и позволяет настраивать кнопки полной карточки.

## Назначение

- Определяет качество **CAM / TS / TC / SD / HD / FHD / 4K** через штатный `Lampa.Parser.get` с уже настроенным внешним JacRed/Jackett.
- Показывает бейджи качества, сохраняет результаты в клиентском и, при необходимости, серверном кэше.
- Повторно проверяет устаревшее качество **при следующем появлении фильма**; периодический обход ранее известных фильмов по умолчанию отключён.
- Добавляет пункт **«Источник»** в фильтр Онлайн для открытия штатного выбора балансера.
- Позволяет менять порядок, видимость и группировку кнопок полной карточки; настройки фильмов и сериалов сохраняются отдельно.

Три клиентские части (`plugin.js`, `online-filter.js` и `buttons.js`) выдаются через единый адрес **`/quality.js`**. Компоненты независимо включаются в `init.conf`.

## Установка и подключение

1. Разместите **всю папку** Quality в каталоге модулей установленного Lampac (`module/Quality/` или `mods/Quality/`). `Modules/Quality/` — путь в исходном репозитории. При обновлении заменяйте и C#-файлы, и все три JavaScript-файла.
2. Убедитесь, что модуль разрешён в `manifest.json` (`"enable": true`) и не исключён настройками загрузчика (`BaseModule.LoadModules` / `BaseModule.SkipModules`). Перезапустите Lampac после установки или изменения файлов модуля.
3. Для встроенной **LampaWeb** при `autoinject=true` скрипт подключается автоматически. Во внешней Lampa установите `https://АДРЕС_LAMPAC/quality.js` как JavaScript-плагин вручную.
4. Полностью перезагрузите Lampa после обновления скрипта или изменения серверных переключателей.

Quality использует настройки существующего `Lampa.Parser.get` (`parser_torrent_type=jackett` и параметры `jackett_*`). Отдельный URL или ключ JacRed модулю не нужны; встроенный серверный `Modules/JacRed` не требуется.

## Конфигурация

Секция **`Quality`** в `init.conf` (поля объявлены в `ModuleConf.cs`):

```json
{
  "Quality": {
    "enable": true,
    "autoinject": true,
    "collect": true,
    "background": true,
    "onlinefilter": true,
    "buttons": true,
    "sqlcache": true
  }
}
```

| Поле | По умолчанию | Назначение |
|------|--------------|------------|
| `enable` | `true` | Главный переключатель модуля: запрещает выдачу плагина и кэш-API при `false`. |
| `autoinject` | `true` | Автоподключение во встроенную LampaWeb; ручная установка `/quality.js` остаётся доступной при `false`. |
| `collect` | `true` | Сбор и показ качества. При `false` фильтр Онлайн и редактор кнопок могут работать отдельно. |
| `background` | `true` | Разрешает **периодическую** перепроверку; её переключатель в самой Lampa по умолчанию выключен. Не запрещает проверку при посещении фильма. |
| `onlinefilter` | `true` | Дополнительный пункт «Источник» в фильтре Онлайн. |
| `buttons` | `true` | Раскладка кнопок и редактор с карандашом. |
| `sqlcache` | `true` | SQLite-кэш Lampac и `POST /quality/cache`; локальный кэш Lampa работает независимо. |

Серверные выключатели имеют приоритет над клиентскими. Для **только фильтра Онлайн и кнопок**, без сбора качества, задайте `"collect": false`, оставив `"onlinefilter": true` и `"buttons": true`.

## Настройки Lampa

Разделы добавляются через `Lampa.SettingsApi`, только если соответствующая функциональность разрешена в `init.conf`.

### Quality — качество

| Настройка | По умолчанию |
|-----------|--------------|
| Показывать бейджи | Да |
| Перепроверять при появлении фильма | Да |
| Периодическое фоновое обновление | **Нет** |
| CAM / TS / TC — интервал проверки | 1 день |
| SD / HD / FHD — интервал проверки | 5 дней |
| 4K — новые фильмы | 10 дней |
| 4K — старые фильмы | 30 дней |
| Ничего не найдено | 1 день |
| Размер SQL-пакета | 30 (если `sqlcache=true`) |
| Фоновая проверка | 15 минут (если `background=true`) |
| Обновить качество сейчас | Ручной запуск проверки ранее известных карточек |

### Quality — другое

| Настройка | По умолчанию |
|-----------|--------------|
| Показывать карандаш | Нет |
| Источник в фильтре Онлайн | Да |

Карандаш открывает редактор кнопок: перемещение, скрытие, режим подписи, папки и сброс. Раскладки сохраняются отдельно в `quality_module_buttons_v2_movie` и `quality_module_buttons_v2_tv`. Скрытие карандаша не сбрасывает их. «Источник» в фильтре Онлайн открывает **штатное** меню балансеров без изменения логики озвучек и сезонов.

При `collect=false` раздел «Quality — качество» не создаётся; «Quality — другое» остаётся, если включён `buttons` или `onlinefilter`. Старые значения клиентских переключателей сохраняются в `Lampa.Storage` — меняется только раздел настроек.

## Обновление качества и кэш

1. **Память Lampa и `Lampa.Storage`** (`quality_module_cache_v6`, до 500 записей) — сначала показывают сохранённый результат.
2. **SQLite Lampac** (`database/quality-cache.db`) — опциональный общий между запусками кэш; пакетные чтение и запись до 30 записей.
3. **Внешний JacRed через `Lampa.Parser.get`** — поиск при отсутствии результата либо при необходимости перепроверки.

По истечении выбранного **интервала перепроверки** старая метка, если она ещё сохранена, остаётся на экране. Когда фильм снова появляется в области просмотра каталога или открывается его полная карточка, Quality делает запрос и заменяет бейдж новым результатом **без перезагрузки страницы**. Например: `TS → FHD`. Ошибка JacRed не удаляет ранее подтверждённое качество.

**Периодический обход невидимых ранее известных фильмов выключен по умолчанию.** Его можно включить отдельно; он работает только при открытой Lampa. Для обновления при появлении фильма этот обход не требуется.

Новые записи SQLite хранятся **180 дней плюс интервал перепроверки**, но запись может быть вытеснена лимитом объёма; ранее сохранённые строки имеют прежний срок. Сервер не выполняет собственный поиск в JacRed и не получает его URL или API-ключи. При недоступности SQLite используются локальные данные и парсер.

Лимиты: до **2 одновременных запросов** к `Lampa.Parser.get`, до **2 SQL-пакетов чтения** и **1 записи**, очередь до **300 заданий**. Включённый периодический обход ограничен тремя новыми проверками в минуту.

## HTTP API

| Маршрут | Назначение |
|---------|------------|
| `GET /quality.js` | Единый JavaScript-плагин Lampa с разрешёнными компонентами. |
| `GET /quality/status` | Текущие серверные переключатели и состояние загрузки модуля. |
| `POST /quality/cache` | Операции `get`, `put`, `get_batch`, `put_batch` с SQLite-кэшем (если `sqlcache=true`). |

SQLite хранит клиентский идентификатор/область аккаунта, отпечатки источника и фильма, метку и сроки кэширования — **без учётных данных JacRed**. Метки поступают от клиента и не подтверждаются серверной проверкой торрентов; общего анонимного кэша нет.

## Файлы и зависимости

| Файл | Назначение |
|------|------------|
| `ModInit.cs`, `ModuleConf.cs` | Инициализация, конфигурация, подключение к LampaWeb. |
| `QualityController.cs`, `QualityCache.cs` | Выдача плагина, HTTP API и SQLite. |
| `plugin.js` | Определение качества, бейджи, кэш и настройки. |
| `online-filter.js` | Интеграция фильтра Онлайн. |
| `buttons.js` | Редактор кнопок полной карточки. |
| `manifest.json`, `Quality.csproj` | Динамическая загрузка и локальная сборка .NET 10. |

Зависимости: Lampac NextGen, клиент Lampa с `Lampa.Parser` / `Lampa.SettingsApi`, существующий внешний JacRed для поиска качества; для серверного кэша — SQLite (`Microsoft.Data.Sqlite`).

## Диагностика и ограничения

- `GET /quality/status` — проверка загрузки и серверных переключателей.
- В консоли Lampa: `window.LampaQuality?.status()`, `window.LampaQualityButtons?.status()`, `window.LampaQualityOnline`.
- Если не отображаются бейджи, проверьте включённые настройки качества и настройку внешнего JacRed в самой Lampa.
- Если фильтр Онлайн или кнопки ведут себя нестандартно, проверьте совместимость с другими плагинами, изменяющими `Lampa.Filter` или панель полной карточки.
- Во внешней Lampa обращения к SQLite могут блокироваться политикой **CORS**; тогда остаются клиентский кэш и поиск через `Lampa.Parser.get`. Долгая работа на отдельных ТВ-устройствах и нестандартных форках Lampa не гарантируется автоматическими тестами.
